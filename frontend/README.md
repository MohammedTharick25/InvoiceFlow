# InvoiceFlow frontend

The React and Vite client uses the app shell in `src/app` and reusable UI wrappers in `src/components/ui`. Radix components are imported only inside these wrappers. Tailwind v4 tokens and the light/dark theme live in `src/styles/theme.css`.

## Local development

From this directory, install the pinned dependencies with `npm ci`, then run:

```sh
npm run dev
npm test
npm run build
npm run test:e2e
```

Playwright's Chromium browser must be installed for `npm run test:e2e`.

The browser auth flow is served at `/auth/login`, `/auth/register`, `/auth/verify-email`, `/auth/forgot-password`, and `/auth/reset-password`. A verified user signs in, creates a business workspace if needed, and then enters the protected app. The client bootstraps and renews sessions through `/auth/refresh`; the refresh credential is held only in the API's HttpOnly, SameSite cookie. Access tokens stay in Zustand memory and are attached as bearer credentials by the API client. Sign out revokes the current server session and clears client memory. Auth tokens in verification and reset links are read from the URL fragment and removed from the address bar before submission.

Configure `VITE_API_BASE_URL` to the backend API origin (for local development, `http://localhost:4000/api`). The API must allow the frontend origin with credentials. The client does not require an external identity provider or paid auth service.

The app shell reads optional feature access from the authenticated API entitlement snapshot. It does not infer features from a plan name. Trial and read-only banners render only when the corresponding server state is passed to the shell. The theme preference is stored in browser local storage.

The app includes customer, invoice, payment, expense, reminder, reports, dashboard, and billing workflows. Marketing trial links to `/register?plan=trial` are accepted alongside the `/auth/register` route.

Reports include six-month cash flow when the server grants that entitlement, customer CSV export when `fullExport` is enabled, and PDF downloads for each report. New customer entry warns about possible duplicates but still allows a deliberate duplicate. Workspace owners can add two clearly labeled sample contacts before they add business records. Expense management includes editable, pausable weekly and monthly recurring expense rules; due entries are generated by the backend scheduler.
